# DSS Taipei Current / 洋流號

Democratic Service Ship. This checkout owns the set's source, revision records and two production workflows. `main` owns authored material; `gh-pages` retains generated publication. Bootstrapping this checkout does not release a replacement package.

The adopted minifigure baseline has **348 rigid pieces, 199 construction operations, 68 main steps and a 102-page legacy PDF**. The Technic baseline has **1101 occurrences and remains a prototype**. Existing Blender source is retained; synchronization of both variants with one shared reference revision remains unproven.

## Start or resume

For a fresh checkout, select the source branch explicitly; the remote default can remain `gh-pages`:

```sh
git clone --branch main https://github.com/clkao/dss-taipei-current.git
```

Read [AGENTS.md](AGENTS.md), [adoption manifest](manifests/adoption.json), then the selected workflow:

- [Model revisions](docs/models/README.md): brief → design → independent model review → done. Reference-only revisions retain Blender/provenance/review artifacts and do not require an MPD.
- [Instruction editions](docs/instructions/README.md): immutable accepted model → authoring → independent instruction review → accepted local delivery. Several editions may share a model revision.

Run from this repository root:

```sh
spacedock status --workflow-dir docs/models --validate
spacedock status --workflow-dir docs/instructions --validate
spacedock status --workflow-dir docs/models --boot
spacedock status --workflow-dir docs/instructions --boot
```

`status --next` reports stage eligibility. It does not authorize dispatch or resolve dependencies. Read each record's dependency hold and require usable tool evidence before dispatch. Historical adoption records do not claim that their creation or review ran through Spacedock.

Mutable state lives on `spacedock-state/models` and `spacedock-state/instructions`, linked at each workflow's ignored `.spacedock-state` path. Source and state commits have separate owners in this same repository. On a fresh clone, use `spacedock state init --workflow-dir docs/models` and the equivalent command for `docs/instructions` to restore the state worktrees from their branches. Use `spacedock codex` to resume orchestration, then select the workflow. Do not create another authoring repository or permanent per-scale branches.

## Reproduce the small migration demonstration

The installed binary is an older modified build, not a clean release of current StudFleet main. Its exact identity and paths are pinned in [tooling.json](manifests/tooling.json). Import needs only that binary:

```sh
/Users/clkao/git/spacedock-research/studfleet/builds/studfleet import-mpd \
  --input sources/minifigure/legacy-v10/source.mpd \
  --out builds/fresh-intake
python3 scripts/adapt_legacy.py --out builds/fresh-adaptation
```

Import output must be a new directory. The adapter intentionally reads the retained bootstrap intake to keep identity stable. It verifies its source and assembly hashes, then maps MPD UUID comments and importer origin chains to all legacy piece IDs. It derives the full 199-operation crosswalk and 68 reader groups in one direction from the accepted source. Never hand-edit a second construction sequence.

[The recorded check](evidence/bootstrap/intake-check.json) confirms 348 unique occurrence mappings and introductions, exact part/color identity, identical authored/compiled piece records except operation-step annotations, and byte-identical adapter replay. `migration/minifigure-v10/assembly.json` is exact admitted `studfleet/assembly-1` geometry. `plan.json` and `presentation.json` explicitly use **DSS intermediate schemas**, not executable StudFleet plan/presentation schemas. No missing copy, supplied-unit or compound-path semantics are fabricated to make a generator accept them.

[Specimens](migration/minifigure-v10/specimens.json) bind speakers (56), life rings (61), compact grouping (1), supplied figures (66/67), side carriers (18/19) and shield approach (53) to exact source operations. Prefix and sweep checks remain declared external evidence. Existing 327-piece/134-page StudFleet work is retained as prior evidence, not current-edition parity.

The explicit shared-catalog inspection ran with `--connectivity pyldraw3` and pinned archive, Shadow and Python inputs. It failed with `connector malformed position: o/3/3/snap_cyl@L11:I0`; see [inspection.json](evidence/bootstrap/inspection.json). The [exact command record](evidence/bootstrap/inspection-command.json) retains its working directory, arguments and `PYTHONDONTWRITEBYTECODE=1` setting. Its `required_failure: false` does **not** make this a pass: the connector backend failed. Connectivity, conservative body coverage, manufacturing, insertion and physical strength remain distinct claims. No new render, full instruction export or physical test ran.
